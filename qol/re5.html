Live lab install: Steam Resident Evil 5 (app 21690). Two pieces only — RE5Fix in the game root, plus a 4GB / Large Address Aware patch on re5dx9.exe.

The feel (read this first!!!)
  • Colour filter off — the stock green/yellow wash is gone.
  • Shadows 4096 (4K-class). FOV bump and FPS cap left off.
  • Ultrawide: UI scaling, crash fix, and pre-rendered movies all on. Resolution limits removed; width/height 0 so it follows the desktop.
  • 4GB LAA on the DX9 exe so heavier mods and longer sessions stay stable. Stock exe backup kept before the patch.
  • Same RE5Fix prefs on Steam Deck (Proton), with the dinput8 loader instead of xinput.

Core

Mod What it does here
RE5Fix (Lyall) DLL hook for ultrawide QoL, colour filter, shadows, optional FOV/FPS. PC loader is xinput1_3.dll plus RE5Fix.ini in the game root.
4GB / Large Address Aware Patched re5dx9.exe for >2GB address space. Helps stability with heavier mods. Stock backup kept next to the exe.

RE5Fix.ini (PC)

What is actually flipped on in the live INI — not every unused slider.

Option Here
Remove Colour Filter on — kills the green/yellow filter
Shadow Quality on at 4096
Remove Resolution Limits on
Custom Resolution 0 × 0 — use the desktop resolution
Fix UI Scaling on (ultrawide)
Fix Ultrawide Crash on
Fix Movies on — pre-rendered videos
Increase FOV off (value 25 unused)
FPS Cap off (value 120 unused)

Steam Deck (Proton)

Piece What it does here
RE5Fix v1.0.4 Same prefs as PC (colour filter off, shadows 4096). Loader is dinput8.dll instead of xinput.
Launch option WINEDLLOVERRIDES="dinput8=n,b" %command%
4GB LAA Same Windows exe patch, running under Proton.

Not in the live load
